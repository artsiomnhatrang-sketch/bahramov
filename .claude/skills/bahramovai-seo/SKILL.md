# Замер SEO и план на его основе

Главное правило проекта: **решения принимаются по цифрам из Вебмастера,
а не по ощущениям.** Весь трафик идёт из Яндекса, Google даёт единицы.

## 1. Снять данные

```bash
python3 scripts/yandex-stats.py --queries
```

Показывает страницы в поиске, топ-запросы, позиции и клики за 30 дней.
Интерфейс Вебмастера ассистенту заблокирован — работать только через API.

Если ответ «Токен не работает» — токен Яндекса живёт около года.
Перевыпустить (приложение пересоздавать НЕ нужно), ссылка:
`https://oauth.yandex.ru/authorize?response_type=token&client_id=146e45f36e154497900ae5492d37e824`
-> «Разрешить» -> скопировать `access_token=` из адресной строки -> заменить
строку `YANDEX_WEBMASTER_TOKEN` в `.env`. Это шаг Артёма, не твой.

## 2. Как читать цифры

- **Много показов + позиция 6–11 + мало кликов** — страница есть в выдаче, но
  сниппет не цепляет. Лечится H1/лидом/description под точную формулировку
  запроса, а не новой статьёй.
- **Много показов и нет своей страницы** — незакрытый кластер, кандидат в статьи.
- **Позиция 1–5, кликов мало** — проблема в заголовке или в самом спросе.
- **Страница просела после правки** — сверить дату правки с git log и
  откатить конкретное изменение, а не переписывать всё.

Сравнивать надо с прошлым замером: он записан в CONTEXT-NOW.md и STATUS.md.

## 3. Что предлагать

Приоритет — **усиление существующих страниц**, а не новые статьи.
Новая страница оправдана, только если у запроса другой поисковый интент,
и это надо показать цифрами. Проверка перед новой статьёй:

```bash
./scripts/preflight.sh --tema "слова темы"
```

«⚠ СИЛЬНОЕ» — писать новую нельзя, усиливать существующую.

Юридические границы, которые не обходим даже ради трафика: реклама средств
обхода блокировок в РФ запрещена, гарантии результата не обещаем,
цифры без источника не ставим.

## 4. Ускорить переобход после правок

```bash
python3 scripts/yandex-recrawl.py
```

`--check` покажет остаток суточной квоты (150/сутки).

## 5. Записать замер

Итог замера — в CONTEXT-NOW.md (кратко, с датой следующей проверки) и
в STATUS.md (подробно, с цифрами до/после). Иначе следующий замер
не с чем будет сравнивать.
