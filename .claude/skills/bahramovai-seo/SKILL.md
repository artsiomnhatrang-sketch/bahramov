# Замер SEO и план на его основе

Главное правило проекта: **решения принимаются по цифрам из Вебмастера,
а не по ощущениям.** Весь трафик идёт из Яндекса, Google даёт единицы.

## 1. Снять данные

```bash
python3 scripts/yandex-stats.py --queries
```

Показывает страницы в поиске, топ-запросы, позиции и клики за 30 дней.
Интерфейс Вебмастера ассистенту заблокирован — работать только через API.

Если ответ «Токен не работает» — токен Яндекса живёт около года.
Перевыпустить (приложение пересоздавать НЕ нужно), ссылка:
`https://oauth.yandex.ru/authorize?response_type=token&client_id=146e45f36e154497900ae5492d37e824`
-> «Разрешить» -> скопировать `access_token=` из адресной строки -> заменить
строку `YANDEX_WEBMASTER_TOKEN` в `.env`. Это шаг Артёма, не твой.

## 2. Как читать цифры

- **Много показов + позиция 6–11 + мало кликов** — страница есть в выдаче, но
  сниппет не цепляет. Лечится H1/лидом/description под точную формулировку
  запроса, а не новой статьёй.
- **Много показов и нет своей страницы** — незакрытый кластер, кандидат в статьи.
- **Позиция 1–5, кликов мало** — проблема в заголовке или в самом спросе.
- **Страница просела после правки** — сверить дату правки с git log и
  откатить конкретное изменение, а не переписывать всё.

Сравнивать надо с прошлым замером: он записан в CONTEXT-NOW.md и STATUS.md.

## 3. Что предлагать

Приоритет — **усиление существующих страниц**, а не новые статьи.
Новая страница оправдана, только если у запроса другой поисковый интент,
и это надо показать цифрами. Проверка перед новой статьёй:

```bash
./scripts/preflight.sh --tema "слова темы"
```

«⚠ СИЛЬНОЕ» — писать новую нельзя, усиливать существующую.

Юридические границы, которые не обходим даже ради трафика: реклама средств
обхода блокировок в РФ запрещена, гарантии результата не обещаем,
цифры без источника не ставим.

## 4. Ускорить переобход после правок

```bash
python3 scripts/yandex-recrawl.py
```

`--check` покажет остаток суточной квоты (150/сутки).

## 5. Записать замер

Итог замера — в CONTEXT-NOW.md (кратко, с датой следующей проверки) и
в STATUS.md (подробно, с цифрами до/после). Иначе следующий замер
не с чем будет сравнивать.

## 5. Разрывы по ключевым словам (добавлено 23.09.2026)

Раздел 2 выше говорит, КАК читать цифры. Этот — чем их считать.

```bash
python3 scripts/keyword-gaps.py
```

Тянет все запросы за 30 дней (около 2200), считает CTR, сравнивает с нормой
для позиции и раскладывает на корзины: **дожать** (топ-10, кликов меньше
нормы), **подтянуть** (11–30), **нет страницы**. Для каждого запроса
показывает, стоит ли фраза в `<title>` дословно.

**Главный рычаг — точная фраза запроса в title.** Проверено 20.09 на своей
выгрузке: при почти одинаковых позициях дословное совпадение дало CTR 16,4 %,
пересказ того же смысла — 1,1 %. Разница в 15 раз.

Три правила, без которых скрипт вредит:

1. **Работающий сниппет не трогать.** CTR выше нормы для позиции — title
   не менять, даже если напрашивается более жирный запрос.
2. **Навигационные запросы к чужому бренду не дожимаются.** «chatplace» —
   221 показ и ноль кликов при точном вхождении. Человек ищет сам сервис.
3. **Смотреть, какими словами спрашивают.** Кириллица шире латиницы:
   «инстаграм» 12 193 показа против «instagram» 843. Достаточно 2–3
   естественных вхождений в title, H1 и лиде.

KD из Ahrefs не нужен: Вебмастер отдаёт факт, а не оценку. Если нас уже
показывают на 4–10 позиции, конкуренция заведомо проходимая.

## 6. Чего от этого ждать, а чего нет

Потолок сайта — не тексты. Их 45. Потолок — **внешние ссылки (подтверждена
одна) и возраст домена (с 25.04.2026)**. Правка title двигает CTR на
существующих позициях; вывести в топ по новому кластеру она не может.

Поэтому в каждом плане должен быть пункт про дистрибуцию, а не только про
правки на сайте. Два применимых пункта схемы Тивари, ещё не взятых в работу:
видео как обход возраста домена (первая продажа пришла YouTube → статья →
услуги) и линкбилдинг. Разбор схемы — `docs/seo-external-playbook.md`.

Эффект правок мерить не раньше чем через 2–3 недели и только в Вебмастере:
в Google 30 страниц из 54 вне индекса, там мерить нечего.

## 7. Решать по CTR страницы, а не запроса (добавлено 23.09.2026)

`keyword-gaps.py` первым блоком печатает **СТРАНИЦЫ**: CTR каждой страницы
против нормы для её средней позиции. Title правится, только если страница
в целом ниже нормы («ПРАВИТЬ» / «ниже нормы»). Отдельный запрос в корзине
«дожать» не повод: 23.09 почти все такие запросы вели на локомотив
регистрации, а у него 7,0 % при норме 3,5 %.

Страница к запросу берётся из API (`query-analytics/list`, сопутствующий URL),
это то, что Яндекс реально показывал. Пометка «угадано» значит, что API
страницу не отдал и привязка сделана по словам title — ей не доверять.
Блок по страницам считается за ~14 дней: столько отдаёт этот метод API.

## 8. План из роликов про AI SEO / GEO (добавлено 25.09.2026)

Второй слой плана - видимость в ответах нейросетей (Алиса, ChatGPT,
Perplexity). Источник - 42 ролика и советы Gemini, разбор и статус по каждому
пункту - `docs/geo-ai-seo-playbook.md`. **Читать его в начале каждого цикла**,
раздел «Что ещё не сделано» - это список дел.

**Сначала ожидания.** Память `pending-external-checks.md` - что ждём снаружи
(Яндекс Исполнители, Habr, TenChat, Bing). Проверить в Chrome и доложить
до начала работы.

**На сайте уже сделано, поддерживать при каждой правке:**
- «Коротко:» под H1, FAQ из 5 вопросов, H2 вопросами, дата «обновлено»
  вместе с `dateModified` (правила - конец CLAUDE.md);
- цены в статьях совпадают с `/uslugi/` - расхождение ломает цитирование;
- свои данные с атрибуцией («на моём аккаунте», «по моим клиентам») -
  нейросети цитируют уникальные цифры охотнее всего;
- после пуша: `python3 scripts/indexnow.py --changed` (Bing и Яндекс),
  плюс `yandex-recrawl.py` для Яндекса;
- ссылки внутри текста от страниц с показами к слабым статьям кластера,
  по смыслу, без блоков «читайте также».

**По датам:**
