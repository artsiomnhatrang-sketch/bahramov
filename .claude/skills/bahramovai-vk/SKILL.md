# ВКонтакте: клипы на странице Артёма

Страница **vk.ru/bahramav** (id162825010, «Артем Бахрамов», номер +375). Упакована 09.10 под разблокировки
Instagram и Telegram: краткая информация, обложка `drafts/vk/vk-oblozhka.png`, сайт bahramovai.com,
закреплённый пост (тексты - `drafts/vk/profil.md`). Тема только разблокировки, взломы, восстановление.

## Не перепутать аккаунт
- Chrome - основной профиль artsiomnhatrang (deviceId 9fb3813f…, названия Browser 1/2/3 меняются).
- Во ВКонтакте в этом профиле два аккаунта: **Артем Бахрамов** (наш) и **Артем Крайко** (таро, сообщество
  «Карты скажут»). Перед любым действием: аватар справа вверху → имя в меню. Не тот - «Другие аккаунты VK ID» →
  Артем Бахрамов. В аккаунт и сообщество таро ничего не грузить.
- Сообщество «Токарные работы» у этого аккаунта - чужая тема, не трогать.
- В окне «Новый клип» автор должен быть «Артем Бахрамов», не сообщество.

## Ролики (решение Артёма 09.10, отдельного «да» на каждый не нужно)
Очередь - `roliki/raspisanie-vk.md` (даты как у YouTube и Дзен). 22:00 по Вьетнаму. За заход 3-4 клипа.
Подпись - блок INSTAGRAM / TIKTOK из `~/Downloads/Ролики bahramovai/NN-имя.txt`; концовку «Напишите мне в Telegram,
ссылка в профиле» / «в директ» заменить на «Напишите мне в личные сообщения», #reels убрать.

Шаги на один клип:
1. vk.ru/clips162825010 → **+ Опубликовать**.
2. Поле файла скрыто: JS делает `input[type=file]` видимым и ставит `aria-label="clip-file-input-0"` →
   `find` → `file_upload` (до 10 МБ). Кнопку «Выбрать файл» не нажимать - откроется системное окно.
3. Ждать ~8 с («Клип загружен»). Клик в поле описания (~676,256), текст абзацами через Enter Enter, хештеги.
4. **Опубликовать в истории** - выключить (клик по подписи переключателя). В истории без решения Артёма не постим.
5. **Когда опубликовать** → день в календаре → поле часа: клик, cmd+a, «22»; курсор сам в минутах: cmd+a, «00» →
   клик мимо календаря. Проверка текста страницы: «<дата> в 22:00» и подпись в textarea.
6. **Запланировать публикацию** (если первый клик только закрыл календарь - второй). Проверка: на странице
   клипов счётчик «Отложенные N» вырос на 1.
7. Статус строки в `roliki/raspisanie-vk.md` → «в отложенных ВК», коммит.

## Грабли
- Обложка профиля: «Изменить обложку» → «Загрузить изображение» создаёт input на лету и вызывает click();
  перехват: подменить `HTMLInputElement.prototype.click`, чтобы input появился на странице, после загрузки вернуть.
- Пост на стене: Enter - перенос строки, публикует кнопка «Далее» → «Опубликовать». «Опубликовать в истории» по
  умолчанию включено - выключать.
- После «Добавить аккаунт» ВКонтакте может отдать 404 на login.vk.ru?act=change_account - аккаунт добавлен,
  просто открыть vk.com/feed.
