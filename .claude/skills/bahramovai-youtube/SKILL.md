# Ролик YouTube → расшифровка → работа

Артём присылает ссылку — дальше всё сам. Решение 30.09.2026: ссылка на YouTube
вместо файла из Gemini Notebook.

## 1. Скачать расшифровку

```bash
python3 scripts/yt-transcript.py "<ссылка>"
```

Файл ложится в `.transcripts/<id>-<слаг>.md` (в .gitignore: чужой текст
в публичный репозиторий не кладём). Шапка: название, канал, дата,
длительность, ручные или авто-субтитры. Дальше абзацы по минуте с меткой
`[мм:сс]`. Повторная ссылка не качается заново (`--force` — заново).

В контекст при этом попадают две строки вывода, а не текст: скачивание
токенов не стоит.

## 2. Читать экономно

Час ролика — около 13 тыс. слов, ~17 тыс. токенов. Целиком читать только
для полного разбора. Иначе:

1. `sed -n '1,12p'` — шапка и первые минуты, о чём ролик.
2. `grep -n -i "ключевое слово" файл` по словам задачи — номера строк.
3. Read с `offset`/`limit` вокруг найденного.

Автосубтитры путают имена и термины (Sanskar → «Sanscar»): имя, цифру или
название сервиса сверять, прежде чем нести в статью или правило.

## 3. Что делать с текстом

- Задача названа — делать её по расшифровке.
- Не названа — 5-7 пунктов о чём ролик + что из этого применимо к проекту
  (сверить с CLAUDE.md, раздел «Title и ключевые слова» — там список того,
  что из чужих схем уже отклонено) + вопрос кнопками, что берём.
- Разбор, который пригодится дальше, — в `docs/<тема>.md` (коммитится,
  на сайт не уходит), со ссылкой на ролик и метками времени. Саму
  расшифровку в docs не копировать.
- Цитаты из ролика в тексты наружу не переносить: пересказ своими словами.

## 4. Если скрипт вернул выход 2

Нет субтитров или YouTube временно режет запросы. Запасные пути через Chrome
(профиль artsiomnhatrang, там вход в Google):

- **Ролик:** открыть, «…ещё» под описанием → «Показать текст видео» → `get_page_text`.
- **Gemini Notebook** (notebook.google.com), если Артём называет блокнот:
  `get_page_text` там отдаёт пустую панель эмодзи — читать через `find`
  («текст ответа в чате», «источник») и `read_page` по найденному ref.
  Официального API у блокнота для личного аккаунта нет — не искать.

Браузер дороже скрипта: текст страницы плюс служебный вывод на каждом шаге.
