# TikTok: отложенные ролики

Аккаунт **@bahram.av**, Chrome-профиль **artsiomnhatrang** (вход по QR 06.10).
Расписание, подписи, статусы и пошаговые грабли - `roliki/raspisanie-tiktok.md`. Читать его первым.

## Правила (решения Артёма 06.10)
- 2 ролика в день: 12:00 и 22:00 по Вьетнаму (08:00 и 18:00 МСК).
- **Не больше 2 загрузок за подход** - после 10 подряд TikTok отдал 429.
- Отдельное «да» на каждый подход не нужно: очередь в raspisanie-tiktok.md одобрена. Новые темы вне списка - сначала показать.
- Подпись = блок INSTAGRAM / TIKTOK из .txt ролика, «ссылка в профиле» -> «Напишите мне в директ», без #reels.
- Окно «Включить автоматическую проверку контента» - Отмена. Шапку профиля не трогать (обновлена 06.10).
- Instagram сюда не входит: туда Артём выкладывает сам с телефона.

## Ход подхода
0. **Какой Chrome (09.10):** расширение само перескакивает между профилями. Перед работой `list_connected_browsers`: основной artsiomnhatrang 08-09.10 был deviceId 9fb3813f…, «Таро» - 79b17215…; названия Browser 1/2/3 меняются, сверять по deviceId. Проверка по странице: на своём канале «Войти» или «Подписаться» вместо «Студии» - не тот профиль или не тот аккаунт, `select_browser` на основной.
1. Chrome занят другим чатом - хук-светофор `~/.claude/hooks/chrome-lock.py` откажет сам; тогда ждать или делать работу без браузера.
   Перед загрузкой сверить, что в TikTok Studio открыт **@bahram.av** (имя в шапке). Другой аккаунт (таро и др.) - переключиться на @bahram.av, ничего не грузить.
2. Вывести окно Chrome вперёд (osascript: окно с tiktok.com -> `set index of w to 1`, `activate`): скрытая вкладка подвешивает загрузку.
3. tiktok.com/tiktokstudio/content - сверить, что уже стоит (`окт, ЧЧ:ММ` с календарём). Выбрать 2 ближайших пустых слота.
4. Для каждого: tiktokstudio/upload -> find input type=file -> file_upload (файл >9 МБ пережать `ffmpeg -crf 24` в scratchpad) -> 8 с, Escape -> клик в поле описания координатой, cmd+a, Delete, текст, хештеги по одному с пробелом -> зум проверить -> радио «Запланировать» -> дата в календаре -> время: JS ищет `.tiktok-timepicker-option-text.tiktok-timepicker-left` с нужным часом (контейнеру `scrollTop`), клик по координатам; минуты 00 так же -> зум проверить -> кнопка «Запланировать».
5. Сверить через поле «Поиск описания публикации» (список грузится кусками, счётчик от отложенных не растёт; 09.10 из-за этого вышел дубль), обновить статусы в raspisanie-tiktok.md, коммит (только свои файлы).
6. Ответ 429 - стоп до следующего подхода, не долбить.
