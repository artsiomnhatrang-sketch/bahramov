`PROJECT-BLUEPRINT.md` (раздел 5 = правила честности).

- **Новостной конвейер (собран 17.08.2026).** Отдельная ветка контент-фабрики:
  горячие ИИ-новости → пост в канал + сценарий Reels, всё по кнопкам в Telegram.
  `scripts/news-daily.sh` — одна команда на весь цикл: `news-collect.py` тянет
  13 источников (западные первоисточники, Habr/vc.ru, Meta Newsroom, веб-зеркала
  каналов @ai_newz / @data_secrets / @seeallochnaya / @denissexy / @telegram)
  в `.news/<дата>.json` → агент **news-editor** отбирает 5 тем с углом подачи →
  `tg-digest.py` шлёт дайджест с inline-кнопками. Владелец жмёт номер,
  `tg-watcher.py` ловит нажатие и запускает **smm-copywriter** (пост) и

  в канал ТОЛЬКО по кнопке «Опубликовать» — автопубликации нет нигде.
  Проверка всего разом: `python3 scripts/tg-watcher.py --selftest`.
  Папка `.news/` в gitignore (сырьё, дайджесты, черновики).
- **Ежедневный дайджест новостей — ОБЛАЧНАЯ routine (создана 22.08.2026).**
  `trig_01DCcmbWjEVdCKxZ3P4aSMoa`, cron `0 1 * * *` = **08:00 ICT каждый день**
  (scout с трендами приходит в 09:00 ICT — специально разведены, чтобы не
  слипались). Работает независимо от Mac и от локального логина CLI.
  ⚠️ **Облачная песочница режет весь исходящий HTTPS из Bash** (403 на CONNECT):
  `news-collect.py` там даёт 0/19 источников, и `api.telegram.org` тоже закрыт.
  Поэтому в облаке сбор идёт через инструменты WebSearch/WebFetch (они ходят
  мимо egress-прокси), а доставка — через **PushNotification на телефон**:
  промпт сначала пробует Telegram один раз, при 403 шлёт полный текст дайджеста
  пушем. Если добавить `api.telegram.org` и домены источников в allowlist
  окружения (env_01PfQ3cxmUjM6mZJykd3VVXv) — обе ветки заработают сами, промпт
  переживёт это без правок. Расширенный список источников в `news-collect.py`
  (платформенная ветка) работает при ЛОКАЛЬНОМ запуске.
  Промпт самодостаточен (роль редактора и токен вшиты) — облако НЕ видит
  `.env` и `.claude/`. Управление: https://claude.ai/code/routines
  ⚠️ **scout ломается на том же месте**: собирает тренд-дайджест и не может
  отправить его в Telegram — каждый день падает на доставке и шлёт пуш.
  ⚠️ Третий источник правды к двум существующим: правила отбора живут и в
  `.claude/agents/news-editor.md`, и в промпте этой routine — синхронить оба.
  **Дайджест делится на два блока:** «Бьёт по услугам» (блокировки, суды и
  регуляторка вокруг Meta/Telegram/WhatsApp — приоритет, работает на услугу
  разблокировки) и «ИИ-фон» (модели и всё остальное). Кнопок в облачном
  дайджесте нет — тему для поста/рилса Артём называет номером в Claude Code.
  ⚠️ Конвейер запускает агентов через `claude -p`, а это **отдельный логин CLI**:
  токен десктопного приложения ему не наследуется. Если selftest пишет
  «CLI claude не авторизован» — открыть Терминал, выполнить `claude`, войти.
  Промпт агенту передавать ТОЛЬКО через stdin: `--allowedTools` вариадический
  и съедает позиционный аргумент.
- **Секреты** в `.env` (gitignored, chmod 600): `TELEGRAM_BOT_TOKEN` (reels-бот),
  `TELEGRAM_CHAT_ID`, `WORDSTAT_TOKEN`. Wordstat: `POST https://api.wordstat.yandex.net/v1/topRequests`,
  `Authorization: Bearer`. ⚠️ **Запись «Яндекс недоступен с Mac по TLS» неверна** (проверено 03.09.2026):
  сеть в порядке, старый API `api.wordstat.yandex.net` просто закрыт. Частотность
  снимать через браузер: `wordstat.yandex.ru/?region=225&words=<фраза>` в claude-in-chrome.
  Новый API — Yandex Cloud Search API, ключ в `.env` (`YANDEX_CLOUD_*`), но не работает
  без привязанного платёжного аккаунта; владелец карту не привязывал.
- ⚠️ Два источника правды: `.claude/agents/scout.md` (локально) и промпт облачной routine —
  при изменениях синхронить ОБА вручную.
