# Завершение сессии

Инструкция переехала в скилл — он же и выполняет всю работу:

**`/bahramovai-finish`** → `.claude/skills/bahramovai-finish/SKILL.md`

Скилл обновляет `CONTEXT-NOW.md` (эта сводка автоматически уходит в следующий
чат), дописывает секцию в `STATUS.md`, правит `CLAUDE.md` при изменении правил,
прогоняет `./scripts/preflight.sh`, коммитит и пушит.

Этот файл оставлен как указатель, чтобы старые ссылки на него не вели в пустоту.
