# Пакет АВТОПИЛОТ (черновик, на сайт пока НЕ выкладывать)

Ведение аккаунта Threads без участия владельца: посты выходят по расписанию,
на комментарии отвечает агент голосом клиента.

**Цена:** сборка 50 000 ₽ единоразово, дальше 10 000 ₽/мес обслуживание.
Решение владельца от 08.09.2026.

## Что входит

| Клиенту говорим | Что за этим стоит |
|---|---|
| Посты выходят сами, вы их только пишете | `threads-post.py`, очередь текстов, публикация по расписанию |
| Не даёт спалить аккаунт постингом пачками | до 3 постов в сутки, интервал 3-4 часа - режим выведен на аккаунте Артёма: 4 поста за 2 часа уронили охват до 1 |
| В комментариях отвечают за вас, вашими словами | `threads-watcher.py` + агент, ответы под постами клиента |
| Видно, заходит контент или нет | `threads-stats.py`, показы и охваты по каждому посту |
| Аккаунт не рискует | официальный Threads API, эмуляции входа нет |

## Как собирается (порядок работ)

1. Созвон с клиентом, шеринг экрана. **Доступы и пароли не берём** - кнопки
   жмёт клиент, Артём говорит куда. Причина: он продаёт возврат угнанных
   аккаунтов, просить пароль от Facebook нельзя.
2. В Facebook клиента создаётся приложение Meta, внутри - приложение Threads.
   Права `threads_basic` + `threads_content_publish`.
3. Аккаунт клиента добавляется тестировщиком Threads, приглашение принимается
   в Threads → Разрешения сайта.
4. Скрипты ставятся на VPS, токен клиента кладётся в окружение.
5. Дальше ежемесячно: продление токена, очередь постов, разбор ответов.

## Границы - проговаривать ДО оплаты

- **Отвечать можно только под постами самого клиента.** В чужих ветках API
  писать не умеет, это делается руками через браузер. Клиенты почти наверняка
  представят себе бота, который ходит по чужим постам - сказать сразу.
- **Нужен Facebook.** Без него приложение Meta не создать. Новый FB под это
  часто банят при регистрации - за этот риск и берётся сборка.
- **Токен живёт 60 дней.** Пропустили продление - всё встало молча.
  Это и есть ежемесячная работа.

## Себестоимость

- VPS (Германия) ~500 ₽/мес, один сервер тянет десяток клиентов
- API модели для ответов на комментарии - единицы долларов в месяц при
  десятках комментариев. Не нулевая статья, но в 10 000 закладывается легко

## Статус

Спроса в поиске нет: `автоматизация threads` - 26 запросов/мес по России,
`сервис автопостинга` - 124. Для сравнения `взломали телеграмм` - ~30 900.
Поэтому страницу на сайте не делаем, пока не будет первых покупателей.

Проверка спроса запущена 08.09.2026: пост опубликован в Threads -
https://www.threads.com/@bahram.av/post/DdBD_9ejzjE
(текст в `threads/posted/19-avtopilot.txt`).

Первый вариант висел час и был удалён владельцем: в нём стояла цена 50 000,
а он решил называть её сам в разговоре. Итоговый пост построен как личная
история - робот опрашивал API каждые три минуты, Meta закрыла доступ за
необычные действия, вернул подтверждением личности. Продукт упоминается
в конце, без цены; финал - вопрос на два варианта ответа, чтобы собрать
комментарии и через них охват.

Ссылка на сайт с меткой `utm_source=threads` стоит по прямому решению
владельца - вопреки замеру, по которому за 14 дней кликов по ссылкам было 0.
Это и проверяем: пойдут ли переходы в Метрике и вопросы в комментарии.
