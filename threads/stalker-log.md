# Журнал ответов в чужих ветках (техника «Сталкер»)

Отвечаем от @bahram.av **через браузер**: официальный API умеет отвечать только
под своими постами, идентификаторы чужих публикаций через него не достать.
Порядок: открыть ветку → поле «Ответьте …» → текст → стрелка отправки.
Лимит комментария тот же, **500 символов**, счётчик виден справа от стрелки.

⚠️ Тексты каждый раз писать заново, а не копировать один и тот же —
одинаковые комментарии под разными постами Meta читает как спам.
⚠️ Темп: не больше 5–6 ответов за подход, между подходами несколько часов.
