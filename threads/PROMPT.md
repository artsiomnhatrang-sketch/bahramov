# Промт для нового чата

Вставлять целиком. Всё остальное ассистент знает из скилла
`.claude/skills/bahramovai-threads/SKILL.md`, раздел «ПОЛНЫЙ ЦИКЛ».

---

Работаем Threads, полный цикл:

1. Найди 30 новых веток, где люди пишут про свою проблему — взломали или заблокировали Instagram, Telegram, WhatsApp, TikTok, увели аккаунт, не приходит код, не проходит проверка личности. Ответь в каждой рекомендацией по существу, тексты новые, без ссылок.
2. Проверь по API комментарии под моими постами и ответь всем, кто ждёт. Если API не идёт — через экран.
3. Опубликуй один пост из очереди.
4. Сними статистику моих постов и обнови контент-план: что залетает, что проваливается, о чём писать дальше.
5. Посмотри, что сейчас работает у конкурентов — ИИ-агенты, чат-боты, нейросети. Форматы, а не темы.

В конце: журнал, коммит, пуш и короткий отчёт.
