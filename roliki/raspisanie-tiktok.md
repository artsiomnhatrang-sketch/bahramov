## Как ставить (грабли 06.10)
- Вкладка должна быть видимой: если Chrome за окном Claude (document.visibilityState = hidden), загрузка висит со спиннером. Вывести окно вперёд через osascript (set index of w to 1, activate).
- Больше ~10 загрузок за раз - 429 Too Many Requests. Не больше 2 загрузок за подход.
- Загрузка: find input type=file -> file_upload (файлы до 10 МБ). Подождать 8 с, Escape (подсказки).
- Подпись: клик по полю описания координатой после загрузки (ref иногда не ловит, остаётся имя файла), cmd+a, Delete, текст, хештеги по одному с пробелом в конце.
- Время: JS ищет .tiktok-timepicker-option-text.tiktok-timepicker-left с текстом 22 -> клик по координатам; минуты: у скролл-контейнера scrollTop=0, затем клик по 00. Проверять зумом.
- Окно Включить автоматическую проверку контента - Отмена (настройка аккаунта). Разрешение хранить видео для отложенной публикации дано Артёмом 06.10.
- Видео в роликах 01-23 в конце говорят ссылка на Telegram в профиле - в шапке TikTok её нет (вопрос Артёму).

- **Вкладка «скрыта» (10.10):** в Chrome несколько окон и профилей; osascript по «первой вкладке с tiktok» выводит не ту. Искать окно, где URL вкладки = tiktokstudio/upload, и `set active tab index of w to N` + `set index of w to 1` + activate; проверка `document.visibilityState` = visible. Загрузка в скрытой вкладке висит - после показа перезагрузить страницу и загрузить файл заново.
- **@ в подписи (10.10):** «@SpamBot» TikTok превращает в упоминание - писать «бот SpamBot» без @.
- **Проверять через поиск (09.10):** список публикаций в TikTok Studio подгружается кусками, innerText видит только видимые строки. Новый отложенный ролик искать полем «Поиск описания публикации», не по тексту страницы и не по счётчику «Публикации: N» (он не растёт от отложенных). 09.10 из-за этого ролик 08 загружен повторно и встал дублем на 12:00.
