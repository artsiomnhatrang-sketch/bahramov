## Как устроено

- Сценарий: `src/texts/<формат>.mjs` — сцены `{ head, say, vis }`: крупный текст, голос, картинка.
  Одна сцена = одна короткая фраза (1,5–3 с), картинка меняется часто.
- Картинки рисует `src/template.html`: `phone` (обобщённый экран с плашкой «Аккаунт отключён», без
  логотипов), `big` (крупная цифра, можно зачеркнуть), `step` (шаг цифрой), `list` (строки, подсветка),
  `chart` (столбики охватов), `flow` (схема автоматизации), `compare` (было / стало), `cta` (финал).
- **Голос: Silero v5 (локально, бесплатно), решение 02.10.** В edge-tts ударение задать нельзя надёжно
  (Артём слышал «тЕлеграм»; знаки то не срабатывают, то портят звук). Silero выполняет «+» всегда.
  Голоса: aidar, eugene (муж.), baya, xenia, kseniya (жен.). По умолчанию baya (выбор Артёма 02.10).
- **Ударения:** `udarenia.py` ставит «+» в КАЖДОЕ слово: ручная «+» в тексте сцены → `slovar.txt` →
  словарь ruaccent (3 млн слов). Односложным тоже (иначе Silero читает «шаг» как «шъг»), кроме предлогов,
  союзов и частиц. Сборка стоит (`--strict`), если слово с двумя ударениями не подтверждено или его нет
  в словаре. Где ударение зависит от смысла — «+» перед ударной гласной прямо в тексте (`плат+ите`, `за чт+о`).
- Порядок: прогнать ударения без видео и проверить глазами каждое слово → сборка → `udarenia/sverka.py`
  (Whisper сверяет голос с текстом пословно; расхождение = ролик не отдавать).
- edge-tts оставлен запасным (`--voice svetlana|dmitry`, режим `--edge`), для роликов не использовать.
- Сборка: `node src/render.mjs --format blokirovka [--n 0] [--voice dmitry|svetlana] [--date ГГГГ-ММ-ДД]`
  → `out/<имя>.mp4` 1080×1920 + `out/<имя>.json` (название, описание). ~1 минута, бесплатно.
- Тренды: `python3 trendy/trendy.py` → `trendy/otchety/<дата>.md` (YouTube, ru + en).
- Загрузка в YouTube Studio — по памятке `youtube-zagruzka.md` (адаптировать под новый канал), только после «да» Артёма.
