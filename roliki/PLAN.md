# Конвейер коротких роликов (Reels, YouTube Shorts) — ниша bahramovai.com

Основа скопирована из `~/Developer/apps/taro/roliki` (ту папку только читаем). Работаем только здесь.

## Как устроено

- Сценарий: `src/texts/<формат>.mjs` — сцены `{ head, say, vis }`: крупный текст, голос, картинка.
  Одна сцена = одна короткая фраза (1,5–3 с), картинка меняется часто.
- Картинки рисует `src/template.html`: `phone` (обобщённый экран с плашкой «Аккаунт отключён», без
  логотипов), `big` (крупная цифра, можно зачеркнуть), `step` (шаг цифрой), `list` (строки, подсветка),
  `chart` (столбики охватов), `flow` (схема автоматизации), `compare` (было / стало), `cta` (финал).
- Голос: edge-tts. Тишину по краям фраз срезаем.
- **Ударения (02.10, после ошибки «пла́тите»):** знак ставится ТОЛЬКО на омографы (слова с двумя
  ударениями) и слова из `udarenia/slovar.txt`; остальное голос читает сам — лишние знаки портят звук.
  Непроверенный омограф останавливает сборку (`udarenia.py --strict`): подтвердить в `slovar.txt`
  или пометкой «+» перед ударной гласной в тексте сцены (`плат+ите`), если ударение зависит от смысла.
  Знак перед «й» нельзя: голос читает «и краткое».
- Порядок: сначала проверить ударения без видео, потом сборка; после сборки `udarenia/sverka.py`
  (Whisper) сверяет голос с текстом, расхождения = ролик не отдавать.
- Сборка: `node src/render.mjs --format blokirovka [--n 0] [--voice dmitry|svetlana] [--date ГГГГ-ММ-ДД]`
  → `out/<имя>.mp4` 1080×1920 + `out/<имя>.json` (название, описание). ~1 минута, бесплатно.
- Тренды: `python3 trendy/trendy.py` → `trendy/otchety/<дата>.md` (YouTube, ru + en).
- Загрузка в YouTube Studio — по памятке `youtube-zagruzka.md` (адаптировать под новый канал), только после «да» Артёма.
