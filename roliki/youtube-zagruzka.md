# Загрузка роликов в YouTube Studio через Chrome (памятка Claude, скопирована из таро-конвейера 2.10.2026)

Канал: @bahramovai, studio.youtube.com/channel/UCXUiSEsUK9PI0odrmoe1Tjg — во ВТОРОМ профиле Chrome
(2.10 это «Browser 2», deviceId 489c5c…; в профиле artsiomnhatrang этого канала нет). Проверять по
адресу Studio: должен быть UCXUiSEsUK9PI0odrmoe1Tjg. Окно «Проверка ещё продолжается» — жать «Опубликовать».
Часовой пояс Studio GMT+7: 18:00 МСК = 22:00.

1. Файл ≤ 10 МБ (ограничение загрузки через расширение): `out/upload/*.mp4` — пережатые
   `ffmpeg -c:v libx264 -preset slow -b:v 1250k -maxrate 1600k -bufsize 3200k`.
2. Открыть `.../videos/upload?d=ud`, file_upload в input type=file.
3. Подождать ~10 с: первая вставка текста сразу после загрузки часто «не попадает» — проверять zoom'ом и
   повторять. Название и описание — из `out/<ролик>.json` (описание живым языком, без «—» и «»).
4. После хэштегов НЕ нажимать Escape (закрывает окно, ролик остаётся черновиком) — кликнуть в поле названия.
5. «Нет, это видео не для детей» → вкладка «Доступ» → «Запланировать публикацию» (развернуть).
6. Дата: клик по кнопке даты → день в календаре кликом. Время: тройной клик по полю, ввести «22:00», Tab.
7. «Запланировать публикацию» иногда срабатывает со второго нажатия. Проверка: окно «Публикация видео
   запланирована» и список Shorts (все «Отложенная публикация»).
8. Ссылки в описании станут нажимаемыми только после проверки канала по телефону (шаг Артёма).

## Как ставили 15 роликов 03.10.2026 (рабочий рецепт)

- Загрузка: `studio.youtube.com/channel/UCXUiSEsUK9PI0odrmoe1Tjg/videos/upload?d=ud` (navigate с force), find
  «file input» → file_upload из `~/Downloads/Ролики bahramovai/`.
- Название: клик по полю (600,306 при окне 1512×699), cmd+a, печатать. Описание: фокус JS
  `querySelectorAll('ytcp-uploads-dialog #textbox[contenteditable]')[1].focus()` и ПЕЧАТАТЬ (computer type).
  **Буфер обмена (pbcopy + cmd+v) не использовать:** другой чат перезаписал его, и в описание ролика ушёл
  чужой служебный текст (поймали и исправили до публикации).
- Дальше JS: радио `VIDEO_MADE_FOR_KIDS_NOT_MFK`, `#next-button` ×3, `#second-container-expand-button`,
  `#datepicker-trigger` → в поле даты insertText «6 окт. 2026 г.» + Enter; время — клик по полю и выбор
  пункта `tp-yt-paper-item` «22:00» из списка (вписывание откатывается на 00:00). Проверить дату/время/название,
  потом `#done-button`, окно «Проверка продолжается» → ОК. Подтверждение: «Публикация видео запланирована».
- Окно «Видео опубликовано» с названием-файлом бывает ложным — проверять статус на странице ролика.
- Расширение Chrome может переключиться на другой профиль (другой чат) — тогда select_browser обратно.
