# Доступы и границы ассистента

**Это постоянный файл: что ассистент может делать сам, а что — только Артём.**
Текущие задачи и приоритеты здесь НЕ живут — они в `CONTEXT-NOW.md`, который
подаётся в новый чат автоматически.

## Что ассистент делает сам, без напоминаний

- **Все проверки:** `./scripts/preflight.sh` перед пушем, `--tema "..."` перед
  новой статьёй. Вопрос «всё ли ок?» = запрос на preflight, а не на пересказ.
- **Google Search Console** — через браузер (Claude in Chrome), Артём залогинен
  под `artsiomnhatrang@gmail.com`, ресурсы: сайт `https://bahramovai.com/`
  и Instagram-профиль `@bahram.av`. Работают запрос индексации, отправка
  sitemap, чтение отчётов.
  *Ловушка интерфейса:* после запроса индексации всплывает диалог, и следующий
  ввод URL часто не проходит — Enter повторно жмёт «Запросить снова». Рабочая
  последовательность: закрыть диалог → клик в строку → пауза 3 с → ввод →
  пауза 2 с → Enter → пауза ~15 с → **отдельным вызовом** клик «Запросить
  индексирование».
- **Яндекс.Вебмастер через API:** `scripts/yandex-stats.py` (позиции и клики),
  `scripts/yandex-recrawl.py` (переобход, квота 150/сутки).
- **IndexNow-пинги** — напрямую через API, ключ `0j0fuyj9g8pu8v1bftid0tymwhnxyxgh`
  (файл лежит в корне сайта).
- **Конвейер статей** — агенты editor → writer → reviewer → publisher
  в `.claude/agents/`.
- **Правки файлов, коммиты и пуш** — по одобренному диффу.

## Что делает только Артём

- **Ввод паролей и вход в любые аккаунты.** Ассистент не аутентифицируется
  от его имени — ни вручную, ни через сохранённые пароли браузера.
- **`publish-article.sh`** — запускает вручную сам.
- **Публикации во внешние каналы** (Telegram-канал, соцсети, площадки) —
  только по отдельному явному «да» на конкретный текст.
- **Яндекс.Вебмастер в браузере** — домен `webmaster.yandex.ru` заблокирован
  политикой. Не пытаться обходить, работать через API.

## Жёсткие запреты

- **Гейт reviewer не обходить** даже по просьбе «сделай всё сам». Статья
  публикуется только после APPROVED.
- **В Search Console без отдельного «да»:** не удалять ресурсы, не менять
  настройки аккаунта, не трогать раздел «Удаления» — оттуда можно случайно
  выкинуть страницы из поиска.
- **Не выдумывать цифры и названия систем Meta.** Правила честности —
  раздел 5 `PROJECT-BLUEPRINT.md`.
- **Не вырезать разделы из опубликованных статей молча** — показать владельцу
  и дать варианты.

## Вывод, который не должен потеряться

Основной проблемой сайта однажды оказалась не разметка, а то, что **Google
не перечитывал карту сайта два с половиной месяца** и знал 29 адресов из 43.
Никакая работа над кодом этого бы не показала — нашлось только в панели.

**Проверять не только сайт, но и панели вебмастеров.** Их отчёты — такой же
источник задач, как аудит репозитория.
