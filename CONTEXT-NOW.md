## Что заблокировано и почему

- **Threads API отдаёт «API access blocked» (OAuthException code 200)** на всех
  эндпоинтах, включая /me. Аккаунт @bahram.av и все посты живы и открываются —
  ограничено именно приложение `bahramovai-threads`. Обнаружено 06.09 при
  финальной проверке, после 4 публикаций за день. Что нужно от Артёма:
  зайти в developers.facebook.com → приложение bahramovai-threads → посмотреть
  уведомления и статус (не переведено ли в ограниченный режим, нет ли требования
  подтвердить бизнес). Локальный агент `com.bahramovai.threads-watcher` каждые
  3 минуты бьётся в закрытый API — остановить:
  `launchctl bootout gui/501/com.bahramovai.threads-watcher`
- **Google не индексирует половину сайта** — лечится ручными запросами
  (лимит ~10–12/сутки) и внешними ссылками. У vc.ru и Т—Бизнес ссылки nofollow,
  веса не дают.
- Wordstat API — нужен платёжный аккаунт, работаем через браузер.
- Дзен: публикация заперта подтверждением телефона, ответа поддержки нет.
