Клонировать «Линию B» — например `instagram-povtornaya-blokirovka-2026.html`. Claude Code открывает референс **дословно**, не восстанавливает по памяти.

## 7. Технические правила правок

- ❌ **Никогда BeautifulSoup для записи** — перезаписывает весь файл с нормализованной разметкой (был случай: 3904 ins / 4922 del вместо 40/40)
- ✅ `str_replace` или `perl` по сырой строке, с гардом «ровно 1 совпадение на файл»
- В perl-заменах использовать `q{}` или одинарные кавычки — иначе `@` интерполируется
- Никаких полных перезаписей файлов — только точечные правки. `git diff` должен показывать низкий churn
- Claude Code **сначала показывает реальные строки**, потом меняет — не гадает по памяти
- zsh: `for f in $VAR` не разбивает по словам → использовать `while IFS= read -r f; do … done < список`
- `cwebp` не установлен (нет Homebrew) → WebP через Pillow: `Image.open(x).save(y,"WEBP",quality=85)`. Не `sips`
- `sips -s formatOptions 80` на уже оптимизированном JPG **увеличивает** размер (188 → 248 КБ)
- GitHub Pages + edge-кеш Fastly TTL ~600 с; `?cb=` не помогает (query-строка игнорируется в ключе кеша) — просто ждать
- Google sitemap ping endpoint отключён с 2023 — убран из `publish-article.sh`

### PDF-генерация
Playwright Chromium, `print_background=True`, нулевые поля; full-bleed через `position:fixed; inset:-2mm`; шрифты base64 в `@font-face` data URI (Google Fonts CDN недоступен — брать raw TTF с GitHub).

## 8. Роли: Claude в чате vs Claude Code

### Claude в чате
- Готовит **промпт** со содержанием статьи — **одним готовым блоком**, не разбитым по сообщениям
- **НЕ создаёт html-файлы** сайта напрямую, не редактирует репозиторий
- Может писать контекстные файлы проекта (этот блюпринт, `*-context.md`, `*-standards.md`) как артефакт
- Читает опубликованные статьи **прямо с сайта** по URL, не гоняет Артёма выгружать текст через терминал

### Claude Code в терминале
- Создаёт/правит файлы, коммитит, пушит
- Все правки HTML/CSS/JS — только через него

## 10. Рабочий процесс публикации статьи

1. **Пре-чек:** сверка на дубль (`grep` — не писать то, что уже есть) + фактчек через web search по быстро меняющимся темам (Telegram / WhatsApp / Meta / законы)
2. Пересчёт статей: `ls -1 blog/*.html | grep -v index | wc -l` — сверить с `CLAUDE.md`
3. **Claude в чате** готовит один готовый промпт для Claude Code
4. **Claude Code** создаёт файл, обновляет `blog/index.html`, `sitemap.xml`, `CLAUDE.md` (счётчик + список) — ровно 4 файла
5. **Claude Code показывает дифф до пуша** — Артём одобряет
6. **Артём вручную** запускает publish (Claude Code сам его не запускает):
```
! cd ~/Developer/bahramov && ./publish-article.sh /blog/имя.html
```
7. Claude **всегда** даёт прямую ссылку: `https://bahramovai.com/blog/имя.html`

В Google Search Console руками заходить не нужно — `publish-article.sh` пингует IndexNow и sitemap.

## 19. Стиль работы Claude в чате

- Кратко, по делу, без филлера. Не повторять одно и то же
- Сначала диагностика, потом действие. Массовая правка = сначала отчёт, потом apply

- Перед подстановкой конкретных цифр — спросить, есть ли реальные данные
- Уважать ранее принятые решения (раздел 17) — не предлагать повторно отвергнутое
- Артём работает в основном **с телефона**, к концу сессии устаёт → лучше меньше проходов, но полных. Промпты для Claude Code самодостаточны с первого раза
- Для вопросов с 2–4 вариантами — интерактивный выбор, удобнее на мобильном
