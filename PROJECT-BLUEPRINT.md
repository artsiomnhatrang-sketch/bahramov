# PROJECT-BLUEPRINT — свод правил для агентов контент-фабрики

Единый справочник для агентов (editor, writer, reviewer, publisher, scriptwriter,
scout). Стабильные правила живут здесь; актуальный список статей, счётчик и статус —
в CLAUDE.md и STATUS.md (не дублировать их сюда).

Ниша: ИИ-агенты, автоматизация соцсетей и мессенджеров, восстановление аккаунтов,
контент-стратегии для бизнеса. Владелец — Артём Бахрам, bahramovai.com.

---

## 1. Эталон вёрстки

Шаблон новой статьи — `blog/train-ai-agent-like-manager.html`. Копируй из него
header, footer, подключение шрифтов, структуру `<head>`, блоки мета и JSON-LD.
Свой шаблон НЕ выдумывать.

CSS-переменные (использовать только их, не хардкодить цвета):

    --bg: #000000      фон
    --bg3: #0a0a0a     карточки/блоки
    --orange: #f4672a  акцент
    --text: #e8e8e8    основной текст
    --muted: #888      второстепенный текст
    --border: rgba(255,255,255,0.07)

Шрифты: Unbounded (заголовки, логотип), Inter (текст). FAQ-секция (`<details>`/
`<summary>`) — копировать стили из `index.html`, свой CSS для FAQ не писать.

Кнопки: если в `.article-body a { color: ... }` задан цвет ссылок — добавить после
`.article-body .btn-primary, .article-body .cta-button { color:#fff !important; }`.

## 2. SEO-требования (обязательны в каждой статье)

- `<title>` 50–60 символов.
- `<meta name="description">` 140–160 символов.
- `canonical`, Open Graph (og:*), Twitter Card.
- Три JSON-LD блока: **Article** (или NewsArticle для срочной новости) +
  **BreadcrumbList** + **FAQPage**.
- Без переспама ключами.

Ключевые темы для перелинковки: AI-агенты, автоматизация Instagram/Telegram,
чат-боты, восстановление аккаунтов, воронки в мессенджерах, личный бренд + AI.

---

## 3. Внутренняя перелинковка

- 3–5 контекстных ссылок в теле статьи.
- Формат: `<a href="/blog/имя.html">естественный якорь</a>` — корневой путь со
  слешом.
- Только первое вхождение якоря. Не self-линковать. Существующие `<a>` не трогать.
- Перед вставкой проверить `ls blog/`, что целевой файл существует. Нет файла —
  пропустить ссылку.

---

## 4. Stat-card (карточки со статистикой)

- Только короткие значения: «78%», «×3», «2–6 ч» — не фразы (2–3 слова максимум).
- CSS-страховка обязательна: `clamp(20px,4vw,32px)` + `word-break:break-word` +
  `overflow-wrap:anywhere`.
- Проверка: `python3 scripts/check-stat-cards.py` должен вернуть exit 0.

## 6. Публикация — гейт владельца

Агенты доводят статью до готового коммита и показывают дифф. Финальную публикацию
(`git push`, IndexNow-пинг, перечитку sitemap) запускает ТОЛЬКО человек вручную:

    ./publish-article.sh /blog/имя-статьи.html

publisher-агент `publish-article.sh` НЕ запускает.

## 8. Дистрибуция (GEO-заметка)

Внешние площадки (vc.ru, Habr) попадают в ответы нейросетей быстрее молодого
домена. Сильную тему editor помечает как кандидата на адаптацию под внешнюю
площадку — адаптацию, не копипаст (Duplicate Content).

---

## 9. Правила честности (жёсткие — главный барьер reviewer)

Любая конкретика проходит тест: **откуда цифра? кейс реальный? термин официальный?**
Не прошло — режь.

- Не выдумывать статистику. Любая цифра — либо с проверяемым источником, либо
  обтекаемая формулировка («по большинству исследований», «значительная часть»).
- Не выдумывать названия систем/обновлений платформ.
- Не делать ранжированных топов конкретных продуктов.
- Не выдавать выдуманные кейсы за реальные.
- Быстро меняющиеся факты (Telegram/WhatsApp/Meta/регуляторика) проверять
  веб-поиском перед сдачей.
- Внешние URL в статье — проверить на HTTP 200.
