Hermes Agent (Гермес агент): что это и нужен ли он, если есть Claude Code

Коротко: Hermes Agent - бесплатный ИИ-агент с открытым кодом от Nous Research. Он ставится на компьютер или сервер, общается с вами через Telegram и другие мессенджеры, помнит прошлые разговоры, сам создаёт навыки и выполняет задачи по расписанию. Если вы уже работаете в Claude Code, Гермес добавляет в основном одно: работу круглосуточно на сервере, пока ваш компьютер выключен.

Про гермес агент сейчас спрашивают постоянно: в Вордстате за месяц около 13,8 тыс. запросов hermes agent и ещё 2,4 тыс. запросов кириллицей. Я каждый день работаю в Claude Code, поэтому разобрал Гермеса с одной стороны: что он даёт тому, у кого Claude Code уже есть.

Что такое Hermes Agent?

Hermes Agent - это программа-агент от исследовательской команды Nous Research. Разработчики называют его самообучающимся агентом: после сложной задачи он сам записывает навык, чтобы в следующий раз сделать похожее быстрее. Код открыт под лицензией MIT, то есть сам агент бесплатный.

Что он умеет по документации:

  • Память между разговорами. Агент ищет по прошлым сессиям и подтягивает нужное, а не начинает каждый раз с нуля.
  • Навыки. Создаёт их сам после сложных задач и умеет брать готовые из общего каталога.
  • Мессенджеры. Telegram, Discord, Slack, WhatsApp, Signal, почта и другие: вы пишете агенту как человеку.
  • Расписание. Встроенный планировщик выполняет задачи в заданное время и присылает результат в мессенджер.
  • Помощники. Агент запускает отдельных субагентов, чтобы вести несколько задач параллельно.
  • Подключения. Поддерживает MCP - стандарт, через который агенты подключаются к сервисам и программам.

Работает на macOS, Linux, Windows и даже на Android через Termux. Есть настольное приложение Hermes Desktop. Сам агент модели не содержит: к нему подключают нейросеть со стороны, от Claude и OpenAI до бесплатных моделей, запущенных прямо на компьютере.

Чем Hermes Agent отличается от Claude Code?

Их часто ставят в один ряд, но задачи у них разные. Claude Code - агент Anthropic для работы с файлами, кодом и задачами на компьютере: он живёт в терминале, в редакторе кода, в настольном приложении и в браузере. Hermes Agent - агент-ассистент, который рассчитан жить на сервере и общаться с вами через мессенджеры.

Главное практическое отличие - где агент живёт. Гермес задуман как постоянно включённый помощник на сервере: компьютер можно закрыть, а агент продолжит отвечать в Telegram и выполнять задачи по расписанию. Claude Code тоже умеет запускать задачи по расписанию, но в моей работе он связан с компьютером, на котором открыт проект.

Можно ли управлять Claude Code через Гермес?

Да, но здесь часто путают, кто кем управляет. Нередко можно услышать, что Гермесом управляют через Claude Code, а по документации связка устроена наоборот. В Гермесе есть встроенный навык claude-code. С ним Гермес становится главным, а Claude Code - исполнителем: Гермес получает задачу, например из Telegram, и передаёт программную часть в Claude Code.

Как это устроено по документации:

  • Claude Code должен быть установлен на той же машине, что и Гермес, и в нём нужно войти в аккаунт Claude или указать ключ API.
  • Короткие задачи Гермес отдаёт в разовом режиме: Claude Code выполняет задачу, возвращает результат и закрывается.
  • Длинные задачи идут в интерактивном режиме: Гермес ведёт сессию Claude Code, дописывает уточнения и следит за ходом работы.
  • Чтобы задача не съела лишнего, задаётся предел шагов и бюджет в долларах на одну задачу.

Простая аналогия: Гермес - секретарь, который принимает поручения в мессенджере, а Claude Code - специалист, которому секретарь передаёт работу с файлами и кодом. Если вы сами сидите за компьютером и даёте задачи Claude Code напрямую, секретарь в цепочке не нужен.

Сколько стоит Hermes Agent?

Сам агент бесплатный. Платить придётся за две вещи: за нейросеть, которая думает за агента, и за сервер, если нужна работа круглосуточно. В документации приводится пример сервера за 5 долларов в месяц.

С моделями есть важная деталь для тех, у кого уже есть подписка Claude:

  • Тариф Claude Pro через вход по подписке не подключается. Остаётся только ключ API с оплатой за каждый запрос.
  • Тариф Claude Max подключается, но по документации Hermes базовый лимит подписки при этом не тратится. Списываются только докупленные сверху кредиты дополнительного использования.
  • Nous Portal - подписка от самих разработчиков, документация называет её рекомендуемым способом: один вход и больше 300 моделей.
  • OpenRouter - один ключ к моделям разных компаний с оплатой за использование.
  • Локальные модели через Ollama работают бесплатно на вашем компьютере, без ключа. Для работы агента документация советует модели с контекстом от 64 тыс. токенов, а такие требуют мощного железа и всё равно уступают облачным.

Итог по цене: подписка Claude, которая уже оплачена ради Claude Code, Гермеса не покрывает. Это отдельная статья расходов.

Кому Гермес нужен, а кому нет?

Гермес имеет смысл, если:

  • агент должен работать круглосуточно, а ваш компьютер выключается на ночь;
  • вы хотите давать задачи голосом или текстом из мессенджера, не открывая ноутбук;
  • нужно переключаться между моделями разных компаний или работать на локальных моделях без отправки данных наружу;
  • у вас есть время настраивать сервер и следить за его безопасностью.

Гермес можно не ставить, если Claude Code уже закрывает ваши задачи. У меня на Claude Code работают сайт и статьи, проверки перед публикацией, аналитика из Яндекс Вебмастера и задачи по расписанию. Гермес из этого списка добавил бы только работу при выключенном компьютере, а взамен потребовал бы отдельную оплату модели, сервер и ещё одного агента с доступом к аккаунтам.

И отдельно про бизнес. Если вам нужен агент, который отвечает клиентам в Instagram или Telegram и доводит их до заявки, это другая задача. Ни Гермес, ни Claude Code для неё не нужны: такой агент собирается на готовой платформе вроде ChatPlace, официального партнёра Meta. Чем он отличается от обычного бота, я разбирал в статье чат-бот или AI-агент, а про сборку в мессенджере - в разборе AI-агентов в Telegram.

На что смотреть перед установкой?

Гермес ставится одной командой с официального сайта Nous Research, для Windows есть отдельная команда через PowerShell. Перед тем как дать ему доступ к своим делам, стоит учесть несколько вещей:

  • Ставьте только с официального сайта или GitHub. Вокруг популярных агентов появляются сайты-двойники с похожими адресами.
  • Агент работает без присмотра. У него есть доступ к терминалу, файлам и тем сервисам, которые вы подключите. Документация позволяет запускать его в изолированном окружении, например в Docker, - этим стоит пользоваться.
  • Не давайте ключи от основных аккаунтов. Для пробы лучше завести отдельные доступы с ограниченными правами.
  • Поставьте лимит расходов у провайдера модели: агент, который сам ставит себе задачи, может потратить больше, чем вы ожидаете.

Частые вопросы

Что такое Hermes Agent?

Бесплатный ИИ-агент с открытым кодом от Nous Research под лицензией MIT. Он ставится на компьютер или сервер, общается через Telegram и другие мессенджеры, помнит прошлые разговоры, сам создаёт навыки и выполняет задачи по расписанию.

Hermes Agent бесплатный?

Сам агент бесплатный. Отдельно оплачивается нейросеть, к которой он подключается, и сервер, если агент должен работать круглосуточно. Бесплатно можно работать только на локальных моделях через Ollama, но им нужен мощный компьютер.

Можно ли подключить Гермес к Claude Code?

Да. Во встроенном навыке claude-code Гермес передаёт задачи с файлами и кодом в Claude Code, установленный на той же машине. Главным в такой связке остаётся Гермес, а Claude Code выполняет поручения.

Работает ли Hermes Agent с подпиской Claude?

По документации Hermes тариф Pro через вход по подписке не подключается, нужен ключ API с оплатой за запросы. Тариф Max подключается, но тратятся только докупленные кредиты дополнительного использования, а не базовый лимит подписки.

Нужен ли Hermes Agent, если уже есть Claude Code?

Если Claude Code закрывает ваши задачи, Гермес добавит в основном работу круглосуточно на сервере, пока компьютер выключен. За это придётся отдельно платить за модель и сервер и следить за безопасностью ещё одного агента.
