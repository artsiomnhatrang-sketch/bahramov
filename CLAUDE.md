# BahramovAI — контекст проекта для Claude Code

## КАК УСТРОЕН КОНТЕКСТ (читать первым)

**Артёму не нужно ничего пересказывать в новом чате.** Состояние проекта
подаётся автоматически: хук `SessionStart` в `.claude/settings.json` запускает
`scripts/session-context.sh`, тот отдаёт сводку — где остановились, что
в репозитории прямо сейчас, какие правила действуют всегда.

| Файл | Что внутри | Кто и когда правит |
|---|---|---|
| `CONTEXT-NOW.md` | **Только «сейчас»**: итог последней сессии, ближайшие задачи, что заблокировано. Держать ≤50 строк | Ассистент в конце каждой сессии |
| `CLAUDE.md` | **Только «всегда»**: правила, список статей, дизайн, workflow | При изменении правил или состава сайта |
| `STATUS.md` | Летопись по сессиям: подробности, цифры до/после, почему так решили | Ассистент в конце сессии |
| `PROJECT-BLUEPRINT.md` | Свод правил для агентов, раздел 5 — честность контента | Редко |

Не дублировать между ними. Если сводка не пришла (хук не сработал) —
прочитать `CONTEXT-NOW.md` вручную, это первое действие в новом чате.

**Проверить, что автозагрузка жива:**
```bash
./scripts/session-context.sh | python3 -m json.tool | head -5
```
Должен получиться валидный JSON. Если хук не срабатывает после клонирования
репозитория — открыть `/hooks` один раз, это перечитывает конфиг.

## СКИЛЛЫ ПРОЕКТА (не переспрашивать, просто применять)

| Скилл | Когда срабатывает |
|---|---|
| `/bahramovai-finish` | «заканчиваем», «на сегодня всё», «могу отдыхать» — обновляет CONTEXT-NOW и STATUS, гоняет preflight, коммитит и пушит |
| `/bahramovai-ship` | «всё ок?», «проверь», «выкладывай» — preflight, дифф, коммит, пуш |
| `/bahramovai-seo` | «как дела с позициями», «работают ли правки» — снимает данные Вебмастера и предлагает, что дожимать |
| `/bahramovai-article` | «напиши статью» — полный стандарт новой статьи |
| `/bahramovai-threads` | «поработаем с Threads», «постим в тредс» — посты из статей в @bahram.av плюс ответы людям в чужих ветках про блокировки; публикация только после «публикуй» |
| `/bahramovai-instagram` | «поработаем с инстаграм», «что по инстаграму» — замер статистики через API, формат публикаций, позиция по аккаунту |
| `/human` | **срабатывает сам** на любом тексте наружу — посты, сторис, описания видео, ответы в личке. Правила тона выведены из 92 152 сообщений Артёма. Вручную звать не нужно |

Скиллы, агенты и настройки лежат в `.claude/` и **хранятся в репозитории** —
при переустановке на новой машине ничего не теряется. Личные разрешения
(`.claude/settings.local.json`) в git не попадают.

**Если Артём повторяет одно и то же указание из сессии в сессию — это сигнал
завести новый скилл или дописать правило сюда, а не выполнять вручную снова.**


## ЦЕЛЬ проекта
SEO + GEO видимость bahramovai.com: ранжироваться в Google и Яндекс по запросам
про AI-агентов и автоматизацию соцсетей. Попадать в ответы нейросетей
(ChatGPT, Perplexity, Gemini, Claude) на вопросы об Артёме Бахраме и его услугах.
Стратегия: экспертный контент с реальными цифрами, тематические кластеры,
JSON-LD, внутренняя перелинковка, регулярный постинг на vc.ru/LinkedIn/Telegram/YouTube.

**Про цифры в статьях:** в уже опубликованных материалах цифры реальные, из
практики Артёма. Их НЕ вычищать. Проверка честности нужна для НОВЫХ текстов:
там цифру надо атрибутировать («по моим клиентам») или дать источник, иначе
reviewer завернёт.

**Автопроверка при пуше.** В репозитории настроен git-хук `.githooks/pre-push`
(включён через `git config core.hooksPath .githooks`). Он сам гоняет
`preflight.sh --fast` при каждом `git push` и блокирует пуш, если сломаны
ссылки, разметка или sitemap. Быстрый режим пропускает только проверку внешних
ссылок (единственная сетевая часть). Обойти в крайнем случае: `git push --no-verify`.

Если хук не срабатывает после клонирования репозитория заново — включить одной
командой: `git config core.hooksPath .githooks`

## Правила работы с Claude в чате
1. **Артём не работает с терминалом.** Команды выполняет ассистент сам. Если команду всё же нужно показать — готовым блоком кода, никогда пересказом словами.
2. **Начало сессии:** контекст приходит сам (хук SessionStart). Ничего просить у Артёма не нужно. Если сводки нет — прочитать `CONTEXT-NOW.md`.
3. **Конец сессии:** применить скилл `/bahramovai-finish` — он обновит CONTEXT-NOW.md и STATUS.md, прогонит проверки и запушит.
4. Перед новой статьёй: `./scripts/preflight.sh --tema "..."` (сверка на дубль) + фактчек по быстрым темам (Telegram/WhatsApp/Meta/регуляторка). Если тема занята — предложить усиление существующей статьи, а не новый файл.
5. Дифф перед пушем — Артём одобряет. publish-article.sh Артём запускает вручную сам. Перед тем как показывать дифф — прогнать `./scripts/preflight.sh`.
6. Артём не обязан помнить про скрипты и правила. Ассистент сам открывает нужный файл контекста и сам запускает проверки. Если Артём спрашивает «всё ли ок» — это запрос на preflight, а не на пересказ.
7. Отвечать по-русски, командами готовыми блоками. Не сваливать на Артёма то, что можно проверить самому.
